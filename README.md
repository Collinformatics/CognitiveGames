# About:

This app provides cognitive exercises to improve your mathmatics skills and working memory.

To select an exercise, or adjust a setting, enter the number or letter associated with the option when prompted.


# Install:

Install necessary packages to your venv with:

    pip install requirements.txt


# Run:

Start the program with the terminal command:

    python CognitiveGames/app.py


## Options:

To begin with the mathematics games add the "--math" flag

    python CognitiveGames/app.py --math

To begin with the memory games add the "--memory" flag

    python CognitiveGames/app.py --memory
